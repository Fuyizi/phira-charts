谱面上传

拖进 .pez → 自动解析 → 确认无误后一键提交到 GitHub

没有访问码则只能使用本页面读取谱面信息。拖进 .pez 文件， 读出曲名、曲师、谱师名义、难度、BPM、时长、音符数，并生成数据条目 —— 全程在浏览器本地解压，解析过程不上传任何文件。
上传文件公开到网页，需要访问码。
访问码由站长发放。初次填写后会保存访问码到本地记住，之后拖进文件点一下即可。 访问码只存在你自己的浏览器里，不会出现在这个页面上，也不会被别人看到。

传完想改信息、改名或删掉？去 创作中心 —— 用同一个访问码登录即可。

把 .pez 文件拖到这里 或者点击选择文件。解析完成后，用上面的「上传这份谱面」按钮提交。

这个工具会替你做什么

  1. 把谱面包拖进来
    自动读出曲名、曲师、谱师名义、难度、BPM、时长、音符数。
  2. 你需要在表单里核对
    并修改字段，特别是「实际谱师」那一栏（包里没有，需要手填）。
  3. 点「上传这份谱面」
    它会自动完成两件事：把 .pez 传到 charts/<id>/<难度>-<版本>.pez， 再把新条目插进 data/charts.js。先传文件、后改数据，避免出现「页面有了、文件还没到」的空窗。
  4. 等 40 秒
    GitHub Pages 自动重建，刷新线上站点就能看到新作品了。

遇到问题

  • 提示「访问码不对」 —— 核对有没有多打空格，或者找站长要一个新的。
  • 提示「连不上后端」 —— 检查一下网络，或稍后重试；一直不行就找站长。
  • 同一份谱面传了两次 —— 只要「谱面 ID + 难度 + 版本号」三项都一样， 第二次会覆盖第一次，不会出现两张重复的卡片。 想发新版就把版本号改掉（比如 v1.0 → v1.1），那会作为新版本收录。
  • 409 冲突 —— data/charts.js 在别处刚被改过。刷新页面重新解析一次再上传。
  • 拖不进文件 / 页面报错 —— 别用 file:// 直接双击打开， 在线站点上正常使用即可；本地预览请起一个 http 服务。

想验证流程又不想真的提交？用「只预览（不提交）」按钮，它会把要做的每一步打出来，但不动仓库。
