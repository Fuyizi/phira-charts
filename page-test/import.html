.pez 导入工具（旧版）

把谱面包拖进来，自动读出曲名、曲师、难度和音符数，生成能直接粘贴的数据条目

这是早期版本，只保留「解析」功能。
新版在 谱面上传 —— 它完全包含这一页，而且能在核对之后直接提交到仓库。 这一页继续留着，是为了老链接不失效。
全程在浏览器本地解压，文件不会上传到任何服务器。支持一次拖入多个文件。
把 .pez 文件拖到这里 或者点击选择文件。支持多选，会逐个解析。也可以直接把文件拖到页面任意位置。

完整的加谱流程

  1. 把谱面包拖进上面的框
    解析完成后点「编辑条目」，把猜错的字段改对。
  2. 把 .pez 本体放进 charts/ 文件夹
    文件名要等于条目里的 id，比如 id 是 aurora， 文件就得叫 charts/aurora.pez。这一步必须手动做，浏览器不能替你存文件。
  3. 把封面另存到 assets/covers/
    右侧预览图右键另存为，命名成 <id>.png 即可。不弄也行，会自动生成占位封面。
  4. 复制代码块，粘进 data/charts.js
    塞进 CHARTS 数组里，注意和上一条之间要有逗号。
  5. 刷新首页
    新作品就出现在列表和侧边栏里了。

解析不出来怎么办

  • 如果提示「不是 zip 格式」——确认一下文件确实是 .pez（可以先把扩展名改成 .zip 用解压软件试开）。
  • 如果曲名、曲师是空的——说明包里的元数据文件名不在常见列表里。 展开「查看压缩包内文件」，看看它用的什么文件，然后手动填进表单即可。
  • 如果音符数是空的——包里没有找到可解析的 chart.json，手动填一下就行，不影响下载功能。

这个工具只是省手工，任何字段都能覆盖。它永远不会修改你的原始文件。
